# 参考图生图规范

用于角色身份控制、剧情表演、姿态动作、场景合成和分镜关键帧。目标是让每张参考图只承担一种清晰职责，并使每次返修可定位、可复跑。

## 一、先判断资产类型

- 身份校准图：中性表情、均匀光、无遮挡，只锁脸、发型、体型或服装。
- 剧情表演图：绑定原文场景、时点、动作、视线、接触物和光源，只改变允许的软组织与身体张力。
- 姿态/构图图：锁骨架、重心、屏幕方向、景别和空间摆位，不提供新身份。
- 场景图：锁空间、入口、前中后景、尺度和光色，不提供角色身份。
- 道具图：锁数量、轮廓、结构、材质、纹样和状态。
- 风格图：只锁渲染语言、材质密度、色彩和光影，不得改变人物五官或道具结构。
- 合成/特效图：锁遮挡边界、发光方向、透明或叠加方式，不烘焙进身份母版。

## 二、参考图选择矩阵

每次生成先写参考清单，逐张标注 `身份 / 结构 / 姿态构图 / 场景空间 / 道具结构 / 风格 / 特效合成` 与 `主参考 / 辅助参考`。

| 目标 | 必须参考 | 条件参考 | 不应单独依赖 |
|---|---|---|---|
| 正脸身份特写 | 已确认正脸或最清晰母图 | 半身衔接 | 远景全身图 |
| 三分之四/侧脸 | 正脸身份主参考 + 对应角度结构参考 | 发型侧后参考 | 只有正脸文字描述 |
| 剧情表情近景 | 正脸身份主参考 + 对应头部角度 | 原文场景、光线参考 | 抽象情绪词、其他人的表情脸 |
| 半身动作 | 正脸身份 + 半身衔接 + 姿态构图 | 服装、手持道具 | 单张头部特写 |
| 全身动作 | 身份特写 + 全身比例/服装 + 姿态 | 场景与道具 | 只用脸部参考 |
| 多人镜头 | 每人各自身份参考 + 布局帧 | 对应角度与服装状态 | 拼贴后不标人物位置 |
| 场景分镜 | 空场景母版 + 镜头布局 | 人物、道具、特效 | 带错误人物的场景图 |

参考数量服从渠道上限。优先级为：主身份 → 对应角度/姿态 → 场景/核心道具 → 风格/特效。超限时先用已确认资产制作布局帧；禁止静默舍弃角色或道具。

## 三、身份不变量与允许变量

生成前把信息分成两栏：

- 不变量：脸宽脸长、三庭、颌角、下巴、眼型眼距、鼻梁鼻头、唇形唇宽、耳朵、发际线、发量轮廓、肤色眼色、颈肩比例、服装版型、配饰位置。
- 本轮唯一允许变量：一个头部角度、一项表情强度、一个姿态、一个服装状态、一个场景或一种光色。

疲惫、震惊、痛苦等不能成为改变骨相的理由。表情依靠眉间与眉峰、上下眼睑、注视点、鼻翼、口角、下颌软组织、呼吸、肩颈和躯干张力表达。先写低强度可观察变化，只有原文明示时才提高强度。

## 四、专业提示词结构

按以下顺序写，使用完整、正向、可观察句子：

1. 资产用途：身份母版、剧情表演锚点、动作锚点或分镜首帧。
2. 参考分工：逐张说明主次和控制职责。
3. 原文情境：地点、时点、刚发生什么、下一刻将发生什么。
4. 身份事实层：逐字复用已确认锁定段，不重新美化五官。
5. 唯一变化层：只写本轮要改变的角度、表情、姿态或状态。
6. 接触与空间：视线对象、手指、虎口、手腕、受力、人物与道具位置。
7. 摄影层：画幅、景别、机位、镜头方向、焦点、安全边距。
8. 光色材质：主光来源、色温、材质响应和背景用途。
9. 风格层：引用项目风格版本，避免堆叠相互冲突的风格词。
10. 不变量与失败条件：短而具体；身份和结构控制不能只靠负面词。

### 人物剧情表情模板

```text
用途：<角色>在<原文场景>中的<镜头/资产>。
参考：图1为主身份参考，只锁脸与发型；图2为对应角度/姿态参考，只锁结构；图3为场景参考，只锁空间与光色。
原文情境：<短引文>。此刻角色正在<动作>，看向<对象>，接触<道具>，由<光源>照明；上一状态<...>，下一状态<...>。
身份不变量：<锁定段>。
本轮唯一变化：<可观察的低强度面部肌肉、视线、呼吸和身体张力>。
构图：<画幅、景别、机位、方向、焦点、安全区>。
通过条件：<身份、表情强度、姿态接触、服装道具、背景、清晰度>。
失败条件：<具体漂移、穿模、数量或方向错误>。
```

## 五、单变量迭代

1. 先锁身份：中性、均匀光、目标角度，不加场景和强情绪。
2. 再锁姿态/构图：加入骨架或布局参考，身份参考仍为主参考。
3. 再加入场景与道具：人物和场景各自沿已确认路径合成。
4. 最后加入光色与特效：不得改变已通过的脸、姿态和物件结构。
5. 每轮只修一个已定位问题；新稿必须复查上一轮已经通过的项目。

不同模型对参考强度和负面提示支持不同。记录实际参数，但规范只规定“身份主参考不得被辅助参考覆盖”，不假设某个跨模型通用数值。

## 六、逐图验收与停止条件

身份类：并排核对脸部轮廓、五官比例、发型、耳朵、肤色和头颈肩；任一骨相漂移即退回。

表演类：先核身份，再核原文情境、表情强度、注视点、呼吸和身体张力；自然疲惫不得表现成换脸、病态妆或夸张哭丧。

动作类：检查重心、关节、五指、虎口、手腕、接触点、受力方向、遮挡和穿模。

场景/道具类：检查空间方向、数量、尺寸、结构、材质、纹样、开合或破损状态以及前后镜连续性。

技术类：主体完整、焦点清晰、无意外裁切、分辨率满足用途、透明背景真实存在（仅在规格要求时）、无文字水印。

失败稿不绑定、不确认、不作为后续参考。自动审查只能给出候选结论；身份与审美必须由实际看图确认。

## 七、复跑记录

每个版本保存：资产 key、母版版本、模型/渠道、全部参考文件、参考职责与主次、提示词全文、尺寸比例、种子或任务参数、生成时间、允许变化项、逐图审核结果和失败原因。确认稿成为下一阶段唯一可选当前版本，旧稿进入历史而不参与自动引用。
