# 逐镜生产包

## 分镜记录

每镜至少记录：

- sourceEvidence：能在原文定位的短引文。
- location、storyTime：具体空间与叙事时点。
- shotPurpose：这一镜唯一要传递的变化。
- startState、endState：姿势、朝向、视线、持物、服装/伤势、道具位置/数量和环境光态。
- continuity：下一镜必须承接的状态。
- assetRefs：key、用途、状态/视图；多文件资产还要选文件。
- description、action、emotion、shotSize、camera、transition、seconds。
- imagePrompt、videoPrompt、质检标准。

## 首帧提示词

首帧是视频可执行的起点，不是剧情摘要。按以下顺序写：主体身份/状态 → 场景和道具锚点 → 静止姿态/接触点/视线/空间关系 → 景别机位与焦点 → 光色材质 → 画风和竖屏安全区。

首帧不写时间过程、对白、声音、运镜或不可见心理。复杂动作选择预备态、接触态或结果态中的一个，并与视频动作边界一致。

## 图生视频提示词

以已确认首帧为输入，只描述：触发 → 主体动作 → 接触/受力 → 次级环境反应 → 运镜 → 明确终点。动作量必须适合本镜秒数；高难度动作拆镜或使用起止帧。

镜头衔接时逐项核对：屏幕方向、视线、动作相位、持物手、道具位置、人物湿润/伤势/服装状态、昼夜和主光方向。

## 镜头数量

镜头数量由可读性、动作阶段和连续性决定，不套固定“爆款镜数”。重要静观、地貌揭示或身份反转可以使用空镜；但空镜同样需要场景资产和状态引用。
