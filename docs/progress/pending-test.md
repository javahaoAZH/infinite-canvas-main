# 待测试

## 桌面程序形态（单 exe 双击启动）

- 编译命令：`cd web; bun run build:desktop` → 将 `web/out` 复制到 `webui/out` → 仓库根目录 `go build -tags desktop -ldflags "-s -w -H windowsgui" -o InfiniteCanvas.exe .`。
- 双击 `InfiniteCanvas.exe` 后，应弹出标题为「无限画布」的独立窗口（WebView2）加载应用；关闭窗口的同时进程退出。
- 未安装 WebView2 Runtime 的机器上应回退为打开系统默认浏览器，并保持后端服务运行。
- 桌面形态下前端与 API 同源运行在 `http://127.0.0.1:端口`（端口可用 `PORT` 环境变量修改），Service Worker、localforage、匿名存储 Cookie 应正常。
- `bun run build:desktop` 脚本：临时移出 `src/app/api` 代理路由后做静态导出，构建后恢复；`bun run build` / Docker 流程不受影响。

## 画布「一键成片」（需真实 FFmpeg 环境人工验证）

- 入口：画布工具栏「一键成片」按钮打开弹窗，自动列出当前画布的视频/配音/图片节点：勾选参与、拖拽或上下箭头排序、图片与配音可填展示时长（默认 5 秒）；仅存本地（未上传云端）的素材置灰并提示先上传。
- 提交后每 5 秒轮询进度：排队中 → 下载素材 → 渲染中 → 完成；完成后弹窗内可预览并下载；失败显示中文错误并可返回编辑重新提交。
- 任务由后端串行执行（并发上限 1），刷新或关闭浏览器不影响继续渲染；服务重启后中断任务标记失败并提示可重新提交。
- 混剪边界：全为同参数 h264 视频时走 concat 免重编码，其余统一重编码到目标尺寸/帧率；图片按时长转视频段、配音补静音黑底画面。

## 成片字幕：烧录与外挂 SRT（需人工验证）

- 「生成字幕」开关开启后展开字幕编辑区：可从对白文本解析（支持 `开始秒-结束秒 文本` 行与纯文本行按总时长均分），也可「AI 切分」复用当前文本渠道生成时间轴（前端做 schema 校验并钳制到总时长内）；条目可编辑并生成 SRT。
- 烧录路径：勾选「烧录进视频」后提交，成片字幕正常显示；未生成 SRT 时提交会被拦截并提示。

- 需重点验证：中文对白烧录后不乱码；Docker/Linux 环境若无微软雅黑字体，libass 回退默认字体导致中文可能缺字形（已知限制）。

## AI 漫剧生产线 /drama（需真实 API Key 人工验证）

- 入口：顶部导航「AI 漫剧」（需登录）；项目新建/切换/重命名/删除均保存在浏览器本地（localforage），刷新后恢复。
- 六步向导：① 剧本：粘贴后可「AI 结构化剧本」（复用文本渠道，输出分镜/角色 JSON 并前端校验，失败可重试，也可跳过手填）；② 分镜：增删改画面描述/对白/时长；③ 角色四视图：每角色生成 4 张立绘候选并分配到正/侧/背/四分之三视图，可「保存到角色库」；④ 分镜图：逐分镜生成，自动携带角色视图作参考图，支持单个重试与生成全部；⑤ 图生视频：逐分镜用分镜图生成视频，带进度；⑥ 配音：逐分镜对白 TTS，完成后提供「发送到画布」与「一键成片」。
- 「发送到画布」组装为画布节点新建画布并跳转；「一键成片」组装时间线创建渲染任务，页面内轮询进度，完成后可预览/下载，失败中文提示可重试。

## /drama 深化集成 drama-skills 八项（需真实 API Key 人工验证）

- ②镜头级可读性词表：分镜图提示词按帧型（有对白 = 对话镜头、含动作/特效关键词 = 动作帧、其余 = 叙事帧）追加 1-2 条针对性可读性约束，不堆万能排除清单。
- ③视频运动配方：图生视频提示词补「静态锚点 → 触发 → 主体动作 → 次级反应 → 运镜 → 终点」因果链要素，并加「运镜不与人物动作争夺注意力」约束。
- ④旁白通道：剧本结构化 JSON 每镜新增可选 `narration` 字段（系统提示词说明规则，无旁白为空）；分镜步骤每镜可编辑旁白；配音步骤把旁白行纳入批量 TTS 并以「旁白 / 对白」标签区分；旁白配音参与发送到画布与一键成片。
- ⑤全局配音指引：设置「默认音频指令」下方新增配音指引说明文案（声音身份与表演分离、判据带反例、易混角色区分、专名发音唯一化），仅作为界面文案，不拼进对白文本。
- ⑥对白手艺：剧本结构化系统提示词精简增补对白手艺要点（先定议程再写句子、潜台词要有推断线索、背景信息带利益进入冲突、停顿打断要有对象和后果、人物声音用策略区分）。
- ⑦AI 审查：分镜步骤页头新增「AI 审查」按钮。机械检查纯前端执行（分镜为空、画面描述为空、时长越界、对白旁白皆空、相邻镜头描述重复、角色无描述），问题镜号红框标出；语义检查为单次文本模型调用（独立评审员系统提示词，审查清单提炼自剧本规则，每条结论要求引用原文短句），输出结构化 findings（blocker/major/minor/note + 位置 + 证据 + 影响 + 建议），顶部整体结论固定三档：通过 / 建议修改 / 需修改，不做数字打分；结果只展示不提供自动改写，不持久化。
- ⑧自定义画风：画面风格下拉尾部新增「自定义」，选中后展开描述输入框（引导写线条/上色/光影/质感；含「高质量/精美」类空泛词时给弱提示，不阻断），自定义内容替换三个视觉步骤的画风基底；未填写等价默认画风。
- 需重点验证：选择题材后结构化剧本是否体现题材校准且不违背用户原文；旁白字段结构化输出与编辑、批量配音、成片链路；AI 审查在无文本渠道时只出机械检查结果的提示；自定义画风切换后三个视觉步骤提示词是否正确替换；旧项目数据（无 genre/customArtStyle/narration）打开不报错。

## 阿里云百炼（DashScope）原生渠道（需真实百炼 API Key 人工验证）

- 渠道接入：前端渠道协议下拉新增「阿里云百炼」，默认 Base URL `https://dashscope.aliyuncs.com`；后端仅做路径映射（图像 / TTS → `/api/v1/services/aigc/multimodal-generation/generation`，视频 → `/api/v1/services/aigc/video-generation/video-synthesis`，任务查询 → `/api/v1/tasks/{id}`，文本 → `/compatible-mode/v1/chat/completions`）与 `X-DashScope-Async: enable` 请求头注入，不新增路由与表结构。
- 建议测试模型：`qwen-image-plus`（图像）、`wan2.6-i2v-flash`（图生视频）、`qwen3-tts-flash`（配音）、`qwen3-max`（文本/剧本）。
- 前置条件：必须登录后使用（百炼无浏览器直连能力，未登录应提示「百炼渠道不支持浏览器直连，请登录后使用本地后端代理」）；管理后台渠道模型列表拉取不支持百炼，需手工填写模型名。
- 需重点验证六点：① 文生图与带参考图编辑正常出图，尺寸「宽x高」映射为「宽*高」；② 图生视频需首帧、无首帧时中文报错，首帧自动压缩为 ≤4MB JPEG，轮询间隔 15 秒、最长 20 分钟，完成后临时 OSS 视频链接自动转存本地；③ qwen3-tts 配音正常（默认音色 Cherry），不支持参考音频时中文报错；④ /drama 全流程（剧本 → 分镜图 → 角色四视图 → 图生视频 → 配音）走百炼渠道跑通；⑤ 视频任务入库与刷新后轮询恢复（后端 `output.task_id` 归一化链路）；⑥ 上游报错（额度不足、参数非法）展示中文错误信息。
