# 待测试

## 桌面程序形态（单 exe 双击启动）

- 编译命令：`cd web; bun run build:desktop` → 将 `web/out` 复制到 `webui/out` → 仓库根目录 `go build -tags desktop -ldflags "-s -w -H windowsgui" -o InfiniteCanvas.exe .`。
- 双击 `InfiniteCanvas.exe` 后，应弹出标题为「无限画布」的独立窗口（WebView2）加载应用；关闭窗口的同时进程退出。
- 未安装 WebView2 Runtime 的机器上应回退为打开系统默认浏览器，并保持后端服务运行。
- 桌面形态下前端与 API 同源运行在 `http://127.0.0.1:端口`（端口可用 `PORT` 环境变量修改），Service Worker、localforage、匿名存储 Cookie 应正常。
- `bun run build:desktop` 脚本：临时移出 `src/app/api` 代理路由后做静态导出，构建后恢复；`bun run build` / Docker 流程不受影响。

- `/admin` 由服务端重定向改为客户端跳转到 `/admin/users`，需确认管理后台入口正常。

## FFmpeg 探测与配置引导（需真实环境人工验证）

- `GET /api/v1/render/ffmpeg-status` 按「后台配置路径 → 环境变量 `FFMPEG_PATH` → 系统 PATH」顺序探测并返回版本信息；需分别验证已安装、未安装、配置路径错误三种情况下的返回与中文提示。
- `POST /api/v1/render/ffmpeg-path` 保存路径后（`settings.private.production.ffmpegPath`）应再次探测生效；一键成片弹窗在 FFmpeg 不可用时显示橙色引导并禁用提交，配置后可恢复；可用时弹窗头部显示弱化的「FFmpeg 已就绪 · 版本号」状态文案。

## 画布「一键成片」（需真实 FFmpeg 环境人工验证）

- 入口：画布工具栏「一键成片」按钮打开弹窗，自动列出当前画布的视频/配音/图片节点：勾选参与、拖拽或上下箭头排序、图片与配音可填展示时长（默认 5 秒）；仅存本地（未上传云端）的素材置灰并提示先上传。
- 提交后每 5 秒轮询进度：排队中 → 下载素材 → 渲染中 → 完成；完成后弹窗内可预览并下载；失败显示中文错误并可返回编辑重新提交。
- 任务由后端串行执行（并发上限 1），刷新或关闭浏览器不影响继续渲染；服务重启后中断任务标记失败并提示可重新提交。
- 混剪边界：全为同参数 h264 视频时走 concat 免重编码，其余统一重编码到目标尺寸/帧率；图片按时长转视频段、配音补静音黑底画面。

## 成片字幕：烧录与外挂 SRT（需人工验证）

- 「生成字幕」开关开启后展开字幕编辑区：可从对白文本解析（支持 `开始秒-结束秒 文本` 行与纯文本行按总时长均分），也可「AI 切分」复用当前文本渠道生成时间轴（前端做 schema 校验并钳制到总时长内）；条目可编辑并生成 SRT。
- 烧录路径：勾选「烧录进视频」后提交，成片字幕正常显示；未生成 SRT 时提交会被拦截并提示。
- 外挂路径：不勾选烧录时，成片完成后结果区提供「下载 SRT」（UTF-8 BOM）。
- 需重点验证：中文对白烧录后不乱码；Docker/Linux 环境若无微软雅黑字体，libass 回退默认字体导致中文可能缺字形（已知限制）。

## 剪映草稿导出（需人工验证）

- 入口：一键成片弹窗底部「导出剪映工程」按钮，不受 FFmpeg 可用性影响；按当前排序/勾选的时间线下载 `jianying-draft-<ts>.zip`，成功/失败均有中文提示。
- 草稿内容：素材存入 `Resources/`，视频/图片进 video 主轨顺序拼接、音频进 audio 轨、SRT 逐条转 text 轨；FFmpeg 不可用时视频时长解析不出则兜底 5 秒/段。
- 需重点验证：解压后的草稿文件夹放入剪映草稿目录（默认 `…/JianyingPro/User Data/Projects/com.liveditor.draft`）后能否被剪映识别打开；不同剪映版本的格式兼容性需实测；素材为相对路径，导入后若未自动绑定需在剪映内手动重新关联（已知限制）。

## AI 漫剧生产线 /drama（需真实 API Key 人工验证）

- 入口：顶部导航「AI 漫剧」（需登录）；项目新建/切换/重命名/删除均保存在浏览器本地（localforage），刷新后恢复。
- 六步向导：① 剧本：粘贴后可「AI 结构化剧本」（复用文本渠道，输出分镜/角色 JSON 并前端校验，失败可重试，也可跳过手填）；② 分镜：增删改画面描述/对白/时长；③ 角色四视图：每角色生成 4 张立绘候选并分配到正/侧/背/四分之三视图，可「保存到角色库」；④ 分镜图：逐分镜生成，自动携带角色视图作参考图，支持单个重试与生成全部；⑤ 图生视频：逐分镜用分镜图生成视频，带进度；⑥ 配音：逐分镜对白 TTS，完成后提供「发送到画布」与「一键成片」。
- 「发送到画布」组装为画布节点新建画布并跳转；「一键成片」组装时间线创建渲染任务，页面内轮询进度，完成后可预览/下载，失败中文提示可重试。
- 需重点验证：未配置各模型渠道时的中文引导提示；批量生成中部分失败时单个重试；刷新页面后项目与各步产物恢复；未登录时本地保存场景。
