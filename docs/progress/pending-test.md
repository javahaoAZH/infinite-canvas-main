# 待测试

## 桌面程序形态（单 exe 双击启动）

- 编译命令：`cd web; bun run build:desktop` → 将 `web/out` 复制到 `webui/out` → 仓库根目录 `go build -tags desktop -ldflags "-s -w -H windowsgui" -o InfiniteCanvas.exe .`。
- 双击 `InfiniteCanvas.exe` 后，应弹出标题为「无限画布」的独立窗口（WebView2）加载应用；关闭窗口的同时进程退出。
- 未安装 WebView2 Runtime 的机器上应回退为打开系统默认浏览器，并保持后端服务运行。
- 桌面形态下前端与 API 同源运行在 `http://127.0.0.1:端口`（端口可用 `PORT` 环境变量修改），Service Worker、localforage、匿名存储 Cookie 应正常。
- `bun run build:desktop` 脚本：临时移出 `src/app/api` 代理路由后做静态导出，构建后恢复；`bun run build` / Docker 流程不受影响。

- 对白分流：已有对白配音的镜头自动切对口型工作流 `minimax_h3_image_audio_to_video`（分镜图+音频驱动，无提示词）；非对白镜头走 v5（首帧=分镜图 + 角色立绘参考图 + 提示词）。自动生产调度新增弱依赖：对白镜视频等本镜配音先执行，配音失败/跳过时视频降级走多图参考路径，不级联跳过。
- 音色参考：角色步骤新增每角色「音色参考」与项目级「旁白音色参考」音频上传（走服务端存储拿公网地址）；indextts2 按参考克隆音色（旁白用项目级默认，对白按对白文本中的角色名匹配角色音色）。ComfyUI 渠道配音产物优先存服务端存储，供对口型工作流回喂（失败回退本地存储不阻塞）。
- 图片注入：新增 MCP 工具 `drama_inject_image`（适配器读本地图片转 base64 → 页面侧上传后写入立绘候选或分镜图；立绘默认自动分配到首个空视图，可用 characterId/characterName 定位）；推荐工作流为注入图片后再 `drama_start_production` 只补跑视频与配音（已有图片幂等跳过）。
- 镜头语言字段：分镜新增可选 shotSize（景别）/camera（运镜）/transition（转场），drama_apply_shots / drama_update_shots 可写入（空串清除）、drama_get_project 回读；分镜图提示词加景别与角色一致性约束词，视频提示词直写指定运镜/转场并常驻画质词；技能目录新增三套词表与爆款节奏规范（开篇爆点、场尾悬念、避免连续三镜以上同景别）。
- 测试方法（最小闭环）：① 按上述配置令牌与渠道；② 注入 3 镜分镜图 → v5 出 1 段非对白视频 → indextts2 出 1 条配音 → 对口型工作流出 1 段对白视频 → 一键成片；③ 确认裸 token 提交/轮询正常、状态 QUEUED→RUNNING→SUCCESS 归一化、成功后产物立即下载落本地（URL 有效期短）；④ 分辨率映射确认（默认 768p 档：768p横/768p竖/768p(1:1) 随画质与画幅切换；对口型工作流无 (1:1) 档，方屏自动降级横屏）；⑤ 音色参考需为真实人声录音（正弦波/音乐等非人声参考会在执行阶段失败，参数校验能过但运行时报通用失败）。
- 设置配置入口（已标准化）：「配置与用户偏好」本地渠道选 ComfyUI 工作流协议即自动登记标准三件套模型（H3 多图参考生视频 / H3 对口型视频 / IndexTTS2 配音），模型选择器内也有推荐模型按钮可点选；默认视频模型自动落 H3 多图参考生视频、默认音频模型自动落 IndexTTS2；历史存留的无效模型名（如 MiniMax-H3）与不完整 Base URL（缺 /comfyui 分组路径）在加载/请求时自动纠正；对口型工作流不进通用视频模型下拉（对白镜分流固定使用），非对白镜固定多图参考工作流，存在 ComfyUI 渠道时视频模型项展示角色分工说明（对白镜自动走对口型、无需手动切换）。
- 已用真实令牌实测验证（协议层）：裸 token 认证、提交/轮询两段式、v5 base64 图片直传出片（QUEUED→RUNNING→SUCCESS 约 50 秒，产物 mp4 下载成功）；indextts2 必填枚举 `emo_control_method` 当前唯一可选值「与音色参考音频相同」（官方示例值「使用情感参考音频」已过期不在 options），其音频入参官方支持 URL/base64（audio/mpeg|audio/wav），无公网地址时前端自动读本地 blob 转 base64 兜底；对口型工作流音频入参文档要求公网 URL（base64 音频仅参数校验通过、执行层未验证，代码保持公网 URL 强制与服务端存储引导），分辨率枚举仅 480p/768p/1080p × 横/竖。
- 风险待验证：浏览器直连 autodl 的 CORS 行为；产物 URL 短有效期（SUCCESS 后立即下载）；indextts2 无语速参数、音色质量依赖参考音频；配音效果不佳时切火山 TTS 为后续待办（本轮未实现）。
