# 待测试

## 桌面程序形态（单 exe 双击启动）

- 编译命令：`cd web; bun run build:desktop` → 将 `web/out` 复制到 `webui/out` → 仓库根目录 `go build -tags desktop -ldflags "-s -w -H windowsgui" -o InfiniteCanvas.exe .`。
- 双击 `InfiniteCanvas.exe` 后，应弹出标题为「无限画布」的独立窗口（WebView2）加载应用；关闭窗口的同时进程退出。
- 未安装 WebView2 Runtime 的机器上应回退为打开系统默认浏览器，并保持后端服务运行。
- 桌面形态下前端与 API 同源运行在 `http://127.0.0.1:端口`（端口可用 `PORT` 环境变量修改），Service Worker、localforage、匿名存储 Cookie 应正常。
- `bun run build:desktop` 脚本：临时移出 `src/app/api` 代理路由后做静态导出，构建后恢复；`bun run build` / Docker 流程不受影响。

## /drama 自动生产（专家团式一键流水线，需真实 API Key 人工验证）

- 入口：/drama 顶部新增「自动生产」按钮（任意步骤可见），运行/暂停中显示已完成/总数徽标；点击打开右侧 560 宽 Drawer。
- 计划预览与成本预估：打开 Drawer 自动基于当前项目生成计划草稿，展示任务分组清单（剧本结构化（可选）→ 立绘 → 分镜图 → 视频 ∥ 配音）与成本预估卡（文本/图像/视频/配音次数，仅统计待执行任务）；选项可调：立绘候选数（1 张省成本 / 4 张）、自动把首选立绘分配到正面视图、是否生成配音；单按钮「确认并开始」。
- 运行与调度：按依赖就绪派发，并发上限文本 1 / 立绘 1 / 分镜图 2 / 视频 2 / 配音 3；失败自动重试 2 次（退避 2s/5s/10s），单任务失败不阻塞无依赖分支；面板提供暂停/继续/终止与总进度、分组进度、任务级状态（视频任务显示百分比），失败任务可单独重试/跳过；跳过某任务时硬依赖它的任务（如视频依赖分镜图）级联跳过。
- 刷新恢复：计划与任务状态持久化到 localforage，刷新后运行中任务重置为待执行、计划转为暂停，点「继续」可续跑（在途视频的服务端轮询不可续接，会重跑该任务）。
- 幂等跳过：已有产物（立绘候选/分镜图/视频/配音）在计划中直接标为已就绪不重复生成，重跑只补缺口；全部完成后不自动合成成片，完成态引导去第 6 步手动「一键成片」。
- 需重点验证：无分镜时计划包含剧本结构化任务（并明示将重置分镜与已生成媒体），结构化完成后自动补齐后续任务；失败镜重试/跳过/终止链路；刷新后恢复续跑；重复确认计划时已有产物不重复计费；六个手动步骤的单独生成/批量生成行为与改造前一致（函数平移无行为变化）。
