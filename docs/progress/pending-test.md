# 待测试

## 桌面程序形态（单 exe 双击启动）

- 编译命令：`cd web; bun run build:desktop` → 将 `web/out` 复制到 `webui/out` → 仓库根目录 `go build -tags desktop -ldflags "-s -w -H windowsgui" -o InfiniteCanvas.exe .`。
- 双击 `InfiniteCanvas.exe` 后，应弹出标题为「无限画布」的独立窗口（WebView2）加载应用；关闭窗口的同时进程退出。
- 未安装 WebView2 Runtime 的机器上应回退为打开系统默认浏览器，并保持后端服务运行。
- 桌面形态下前端与 API 同源运行在 `http://127.0.0.1:端口`（端口可用 `PORT` 环境变量修改），Service Worker、localforage、匿名存储 Cookie 应正常。
- 新增 `bun run build:desktop` 脚本：临时移出 `src/app/api` 代理路由后做静态导出，构建后恢复；`bun run build` / Docker 流程不受影响。

## 画布路由调整（所有运行形态均生效）

- 画布编辑页由动态路由 `/canvas/:id` 改为静态路由 `/canvas/view?id=xxx`，需回归：首页创建画布跳转、画布库卡片打开、画布内新建画布跳转均可正常进入对应画布。
- `/admin` 由服务端重定向改为客户端跳转到 `/admin/users`，需确认管理后台入口正常。

## 导演模式修复（已复测，结果记录如下）

- 导演模式静态路由直达修复：`/director/index.html` 直达返回 200，不再 301 到 SPA —— 已验证通过。
- 导演模式退出：常驻「×」关闭按钮与 `Esc` 键退出均已验证可用；`Esc` 在导演 iframe 内监听并通过 postMessage 通知父页面关闭，父页面保留顶层 window 兜底监听，焦点在父页面或 iframe 内均可正常退出。
- 上传超时保护：图片上传超时 120 秒、视频/音频上传超时 300 秒 —— 已实现，属于防御性改动，无需额外复测。
- 新节点级联偏移放置：新建节点位置按画布中心偏移，避免与先前节点重叠 —— 已实现。
- **完整 E2E 回归（核心链路全部正常）**：

  - 相机截图发送到画布正常；
